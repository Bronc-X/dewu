# Image-2 五版设计方向

说明：本轮原计划直接用 image-2 生成五张新图，但当前会话没有暴露 Codex 原生 image_gen 工具；CLI 回退使用本机 Codex auth.json 里的 API 凭据时返回 401。因此这里先交付五版方向板与可重跑 prompts。等原生 image_gen 可用，或登录 API 能力可被 CLI 正确调用时，可直接按 prompts.jsonl 重跑。

## 01 高级真实花园派对
适合：更真实、更像商业摄影，后续产品合成最稳。

## 02 街头潮流生日派对
适合：更年轻、更抓眼，适合社媒封面，但要控制背景不要抢产品。

## 03 电影感夕阳户外
适合：情绪最好、质感强，但最终合成要注意产品光线匹配。

## 04 童趣花墙礼物场景
适合：生日主题最直接、儿童氛围最明显，商业转化友好。

## 05 干净电商棚景
适合：最安全、产品最突出，但可能不够“生日 Party”。
